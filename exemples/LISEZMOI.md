# Fichiers d'exemple

| Fichier | Sert à | Onglet |
|---|---|---|
| `couleurs_exemple.csv` | associer une couleur à chaque abréviation de système | Coloration |
| `couleurs_exemple_virgule.csv` | le même type de fichier, séparé par des virgules (format produit par le script Dynamo du dossier `rvt/`) | Coloration |
| `parametres_IFC4.json` | gabarit de paramètres pour une maquette IFC4 (bouton **Importer**) | Coloration → Paramètres |
| `parametres_IFC2X3.json` | gabarit de paramètres pour une maquette IFC2x3 | Coloration → Paramètres |
| `proprietes_exemple.csv` | ajouter des propriétés à des éléments par GUID | Ajout Pset |

Le séparateur des CSV peut être `;` ou `,` : l'application le détecte automatiquement.

Les abréviations, noms de Pset et GUID sont donnés à titre d'exemple : remplacez-les
par ceux de vos maquettes. Les GUID de `proprietes_exemple.csv` n'existent dans
aucune maquette réelle : ils seront signalés comme « introuvables ».
